Antes de empezar.

¿Puede ser una web de una sola página?+

Sí. Si una página explica bien la oferta y cubre las funciones necesarias, no hace falta empezar con un sitio grande.

¿Puedes conectar una web a un XML?+

Sí. Finques Salpí es un ejemplo de web inmobiliaria alimentada con datos de un archivo XML. Cada fuente se revisa antes de definir su integración.

¿El desarrollo incluye posicionamiento?+

El alcance puede incluir la base técnica: títulos, páginas rastreables, estructura y rendimiento. El posicionamiento también depende del contenido, la competencia y la evolución del sitio; no se prometen posiciones.

¿Cómo se define el presupuesto?+

Según páginas, diseño, contenidos, funcionalidades e integraciones. La propuesta concreta qué entra y qué necesita aportar cada parte.
